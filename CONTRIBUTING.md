# Contributing to LLM Hallucination Checker Edge

Thank you for considering a contribution. This project is a small, dependency-light, OpenTelemetry-native diagnostic utility. It reports structural signals in GenAI traces—such as empty completions, missing citation markers, and missing model metadata—using deterministic, offline heuristics. **It does not verify factual correctness or reliably detect hallucinations.** Contributions should preserve that honest scope, avoid presenting heuristic signals as truth judgments, and keep the three implementations consistent.

Following these guidelines helps communicate that you respect the maintainers' time. In return, we'll reciprocate that respect by addressing your issues, assessing changes, and helping you finalize pull requests.
